# POC: Authentication

Demonstrates authentication and authorization with Spring Security.

## Goals
- Form login vs stateless (JWT) authentication
- Password hashing (BCrypt)
- Role-based access control (RBAC)
- Method-level security
- Token refresh flows (concept + example)

## Run (planned)
```bash
mvn -pl pocs/authentication -am spring-boot:run
```
