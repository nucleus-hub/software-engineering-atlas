# POC: Cloud

Documentation-first POC for cloud-native concepts. Provider-specific code
will be added as standalone projects (kept out of the core build to avoid
forcing cloud SDKs on every developer).

## Planned experiments
- Object storage (upload/download, signed URLs)
- Managed queues / pub-sub
- Serverless functions
- Infrastructure as Code basics
- Autoscaling and cost/perf trade-offs

## Status
Notes only. Not yet part of the Maven aggregate build.
