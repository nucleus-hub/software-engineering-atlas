# Design Patterns

Runnable Java examples of classic and enterprise design patterns.

## Categories
- **Creational:** Singleton, Factory Method, Abstract Factory, Builder, Prototype
- **Structural:** Adapter, Decorator, Facade, Proxy, Composite, Bridge, Flyweight
- **Behavioral:** Strategy, Observer, Command, Template Method, State, Iterator, Mediator, Chain of Responsibility
- **Enterprise/Spring:** Dependency Injection, Repository, DTO, Specification

Each pattern should include: intent, when to use, a runnable example, and trade-offs.

## Run / Test
```bash
mvn -pl backend/design-patterns -am test
```
