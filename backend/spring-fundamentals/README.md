# Spring Fundamentals

Core Spring / Spring Boot concepts with runnable examples.

## Topics
- Inversion of Control (IoC) & Dependency Injection
- Bean lifecycle, scopes, and `@Configuration`
- Property binding, profiles, and externalized config
- Spring Boot auto-configuration and starters
- Application events and `ApplicationRunner`

## Run / Test
```bash
mvn -pl backend/spring-fundamentals -am test
```
