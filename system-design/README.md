# System Design

Deep-dive notes on designing large, reliable, scalable systems. These are
**living documents** — refine them as your understanding grows. Every note
ends with a **Trade-offs** section, because system design is the art of
choosing which problems to have.

## How to use these notes
- Read a topic, then try to **draw the system** from memory.
- For any decision, ask: *what does this optimize for, and what does it cost?*
- Tie theory back to the **POCs** folder — build small versions to feel the concepts.
